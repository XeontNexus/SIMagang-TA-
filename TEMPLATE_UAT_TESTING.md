## **PART IV: FORMULA SINTESIS PERHITUNGAN SKOR AKHIR UAT**

Setelah seluruh responden mengisi kuesioner, rekaplah jawaban responden untuk dihitung persentase kelayakannya menggunakan rumus kelayakan UAT:

### **1. Cara Menghitung Skor Kelayakan Per Kategori Responden:**
1.  Hitung **Skor Aktual** = (Jumlah pilihan STS $\times 1$) + (Jumlah pilihan TS $\times 2$) + (Jumlah pilihan N $\times 3$) + (Jumlah pilihan S $\times 4$) + (Jumlah pilihan SS $\times 5$)
2.  Hitung **Skor Maksimum** = Jumlah Responden $\times$ Jumlah Pertanyaan $\times 5$
3.  Hitung **Persentase Kelayakan ($P$)**:
    $$P = \frac{\text{Skor Aktual}}{\text{Skor Maksimum}} \times 100\%$$

### **2. Tabel Rekapitulasi Hasil Akhir UAT (Diisi Setelah Pengujian):**

| Aspek Pengujian | Skor Aktual | Skor Maksimum | Persentase Kelayakan (%) | Kategori Kelayakan |
| :--- | :---: | :---: | :---: | :--- |
| **Usability** | ____________ | ____________ | ____________ % | |
| **Functionality** | ____________ | ____________ | ____________ % | |
| **Interface** | ____________ | ____________ | ____________ % | |
| **Reliability** | ____________ | ____________ | ____________ % | |
| **Rata-rata Total** | **____________** | **____________** | **____________ %** | **[ ] SANGAT LAYAK / [ ] LAYAK** |

### **3. Kriteria Interpretasi Kelayakan UAT:**
*   **$0\% - 20\%$** : Sangat Tidak Layak / Sangat Tidak Setuju
*   **$21\% - 40\%$** : Tidak Layak / Tidak Setuju
*   **$41\% - 60\%$** : Cukup Layak / Netral
*   **$61\% - 80\%$** : Layak / Setuju
*   **$81\% - 100\%$** : **Sangat Layak / Sangat Setuju**
